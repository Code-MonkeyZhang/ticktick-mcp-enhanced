Query tasks with flexible filtering. All parameters optional; combine with AND logic.

task_id: get a specific task (combine with project_id for direct lookup).
project_id: limit to project ("inbox" for inbox).
date_filter: "today"|"tomorrow"|"overdue"|"next_7_days"|"custom".
custom_days: days from today (only with date_filter="custom").
priority: "none"|"low"|"medium"|"high".
search_term: keyword in title, content, or subtask titles.
