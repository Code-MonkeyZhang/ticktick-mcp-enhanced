Query completed (finished) tasks.

All parameters are optional. When no filters are provided, returns all completed tasks.

Args:
    project_id: Limit results to a specific project. When omitted, searches across all projects.
    date_filter: Quick date range filter for completion time - one of:
        - "today": Tasks completed today
        - "yesterday": Tasks completed yesterday
        - "this_week": Tasks completed this week (Monday to Sunday)
        - "this_month": Tasks completed this month
        - "custom": Custom date range (requires start_date and end_date)
    start_date: Start of custom date range (ISO format with timezone, e.g., "2026-05-01T00:00:00+0800").
            Only used when date_filter="custom". Filters tasks where completedTime >= start_date.
    end_date: End of custom date range (ISO format with timezone, e.g., "2026-05-21T23:59:59+0800").
            Only used when date_filter="custom". Filters tasks where completedTime <= end_date.

Examples:
    get_completed_tasks()                                         → All completed tasks
    get_completed_tasks(date_filter="today")                      → Tasks completed today
    get_completed_tasks(date_filter="this_week")                  → Tasks completed this week
    get_completed_tasks(project_id="abc123")                      → Completed tasks in a specific project
    get_completed_tasks(date_filter="custom", start_date="2026-05-01T00:00:00+0800", end_date="2026-05-21T23:59:59+0800")
                                                                  → Completed tasks in a custom date range
