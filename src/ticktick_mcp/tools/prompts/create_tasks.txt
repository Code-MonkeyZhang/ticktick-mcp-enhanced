Create one or more tasks.

Each task: title, project_id, time_zone (required). Optional: content, start_date, due_date (ISO datetime with timezone, e.g. "2025-12-16T08:00:00+0000"), priority ("none"|"low"|"medium"|"high"), repeat_flag (iCal RRULE, e.g. "RRULE:FREQ=DAILY;INTERVAL=1"), items (subtask list), reminders (iCal TRIGGER, e.g. ["TRIGGER:PT0S"]). Without reminders, no alarm fires even with due_date.
